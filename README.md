# Satellite-image-based-Water-quality-modeling-for-River-Yamuna
This repository is for the resources , datasets and other necessary things used for building the River water quality monitoring system for Yamuna River. Here, the final dataset is the 
dataset that we used to train our models that we compared in our paper. Datasets were built using existing publicly available datasets and processed by our team. For the 
model part, the model parameters and other aspects were decided by me and trained using the datasets. This repository also stores some research papers that we took help from for 
writing this paper.
